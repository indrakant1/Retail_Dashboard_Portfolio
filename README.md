# 📊 Smart Retail Analytics

Smart Retail Analytics is an interactive data analytics dashboard designed to analyze customer behavior, revenue, purchases, orders, product categories, and recommendation performance.

## 🚀 Project Overview

This project provides business insights from retail interaction data using an interactive dashboard.

### Key KPIs

- 💰 Total Revenue
- 📦 Total Quantity
- 🛒 Total Purchases
- 📋 Total Orders
- 👥 Total Customers
- 🖱️ Total Clicks

## 📈 Dashboard Features

### 1. Revenue Trend
Displays total revenue by interaction date and helps identify revenue trends over time.

### 2. Revenue by Product Category
Analyzes revenue generated by different product categories such as:

- Fashion
- Electronics
- Home & Living
- Beauty
- Groceries
- Sports
- Footwear
- Books
- Toys
- Accessories

### 3. Revenue by Recommendation Type

Compares revenue generated from different recommendation strategies:

- Personalized
- Trending
- Similar Products
- Frequently Bought
- New Arrival
- Discount Based
